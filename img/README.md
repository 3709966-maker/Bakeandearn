# Фото для сайту

Покладіть сюди фото з такими назвами (вони прописані в `data/gallery.json`):

- `hero.jpg` – головне фото вгорі сторінки (вертикальне, 4:5)
- `cake-01.jpg` … `cake-08.jpg` – галерея робіт

Фото, якого тут немає, на сайті просто не показується.

Щоб сайт швидко відкривався: ширина 1000–1200 px, розмір до 200 КБ.
Стиснути можна безкоштовно на https://squoosh.app (формат WebP або MozJPEG, якість 75).
Якщо зберігаєте у WebP, змініть назву файлу і в `data/gallery.json`.
