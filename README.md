# Сайт Bliscake

Односторінковий сайт кондитерської трьома мовами: польська (головна, `/`), українська (`/uk/`), англійська (`/en/`).
Мета сторінки – щоб клієнт знайшов відповіді на свої питання й залишив заявку на розрахунок.

Порядок блоків: перший екран → фото → чому ми → як замовити (4 кроки, передплата) → калькулятор ваги й ціни → прайс → відгуки Google → форма заявки → питання → контакти.
На телефоні внизу завжди видно кнопки «WhatsApp» і «Розрахувати ціну».

## Де що змінювати

Усе редагується в папці `data/`, код чіпати не потрібно.

| Що змінити | Файл |
|---|---|
| Ціни, назви й описи смаків, нові позиції | `data/prices.json` |
| Тексти сайту, питання й відповіді | `data/i18n/uk.json`, `pl.json`, `en.json` |
| Телефон, адреса, соцмережі, передплата, кількість відгуків, коди аналітики | `data/settings.json` |
| Фото | папка `img/` + `data/gallery.json` |
| Кольори | початок файлу `src/style.css` |

**Ціна змінюється в одному місці.** У `prices.json` кожна позиція має одне число `price`, яке показується всіма трьома мовами. Калькулятор теж бере ціни звідти.

Редагувати можна просто на GitHub: відкрийте файл → іконка олівця → змініть → «Commit changes». Сайт оновиться сам за 1–2 хвилини.
Лапки `"` і коми між блоками залишайте на місці. Якщо збірка падає, найчастіше причина в пропущеній комі.

## Аналітика: Google і Meta

Усі коди вставляються в `data/settings.json`. HTML редагувати не потрібно, коди потраплять на всі сторінки автоматично.

**Варіант 1 (рекомендований): Google Tag Manager**

1. Створіть контейнер на https://tagmanager.google.com і скопіюйте ID виду `GTM-XXXXXXX`.
2. Вставте його в `"gtmId": "GTM-XXXXXXX"`.
3. Уже всередині GTM додайте теги:
   - **Google Analytics 4** (Google tag з вашим `G-…`), тригер «Initialization – All Pages».
   - **Meta Pixel**: шаблон «Facebook Pixel» з Community Template Gallery, тригер «All Pages»; у налаштуваннях згоди тегу вкажіть «Require additional consent: ad_storage».
   - Конверсії: тригер Custom Event `generate_lead` → подія GA4 `generate_lead` і Meta `Lead`.

**Варіант 2: без GTM.** Заповніть `"ga4Id": "G-XXXXXXX"` і/або `"metaPixelId": "1234567890"`. Подія заявки (`Lead`) відправляється автоматично.

**Події, які сайт надсилає сам** (у `dataLayer` для GTM і напряму в GA4/Pixel):

| Подія | Коли |
|---|---|
| `generate_lead` | заявка надіслана (головна конверсія) |
| `form_start` | людина почала заповнювати форму |
| `calculator_use` | натиснула «Залишити заявку» в калькуляторі |
| `contact_click` (`method`: whatsapp / phone / instagram / email / telegram / facebook) | клік на контакт |

**Згода на cookies.** Якщо вказано хоча б один код, з’являється банер згоди (вимога RODO/GDPR). Підключено Google Consent Mode v2: до згоди Google не зберігає cookies, а Meta Pixel не завантажується зовсім.

## Заявки з форми

- Поки `formAccessKey` порожній, заявка відкривається у WhatsApp з уже заповненим текстом.
- Щоб заявки приходили на пошту: зареєструйтесь безкоштовно на https://web3forms.com з адресою anilllbb@gmail.com, скопіюйте Access Key у `"formAccessKey"`. Після надсилання клієнт бачить кнопку, щоб дописати вам у WhatsApp і надіслати фото-приклад.

## Публікація

Сайт – звичайні статичні файли, тому хостинг безкоштовний і швидкий.

**GitHub Pages (налаштовано):** Settings → Pages → Source: «GitHub Actions». Кожна зміна в гілці `main` публікується автоматично (`.github/workflows/deploy.yml`).
Свій домен: впишіть його в `"customDomain"` (наприклад `bliscake.com`) і в `"siteUrl"`, а в DNS домену додайте записи для GitHub Pages.

**Cloudflare Pages або Netlify:** команда збірки `node build.js`, папка `dist`.

Перевірити локально: `node build.js --local` і відкрити `dist/index.html` у браузері (посилання між мовами ведуть прямо на файли). Для публікації збирайте без `--local`.

## Швидкість

Без фреймворків і без зовнішніх шрифтів (системні шрифти). Стилі вбудовані в сторінку, скрипт 8 КБ, фото завантажуються ліниво. Сторінка без фото важить близько 40 КБ.
Головне для швидкості далі – стискати фото (див. `img/README.md`).

## Сторінка продажу таблиці Bake & Earn

Окрема сторінка в папці `bakeandearn/` (один файл `index.html`, не пов'язана зі сайтом Bliscake).
Налаштування на початку файлу, у блоці `CONFIG`: посилання на оплату 199 і 699 грн, Telegram-бот, ID відео YouTube.
Поки посилань на оплату немає, кнопки ведуть у бот (`?start=basic` / `?start=pro`).
Опублікувати: перетягнути папку `bakeandearn` на https://app.netlify.com/drop або підключити окремий хостинг.
